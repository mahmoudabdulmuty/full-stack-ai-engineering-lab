Module 1. A variable is a name tag, not a box. And Python never guesses across types.

Core model: x = 5 hangs a name tag on a value. Reassigning moves the tag to a different box — the old box is orphaned. And when two types meet in an operation, Python refuses to guess: compare → False, arithmetic → crash.

The no-coercion court

—Press a button. Predict first: False, "55", or a crash?
In JS: "5" == 5 → true (coerces!) and "5" + 5 → "55". Python does neither. It fails loud instead of guessing wrong.
Why dynamic typing matters here: the tag moves, the type lives in the VALUE — type(x) just reads whatever box the tag currently hangs on. That's why type() worked on everything since Module 1: strings, ints, lists, dicts — one tag, many possible boxes.
