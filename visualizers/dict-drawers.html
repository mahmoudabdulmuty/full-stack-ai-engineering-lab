Visualizer — Dictionary Drawers

Module 2, Lesson 3. A dict is a wall of labeled drawers. You look up by LABEL — never by drawer position.

Core model: d[key] opens the drawer with that exact label. No label? Python doesn't shrug like JS undefined — it crashes with KeyError. .get() is the polite version: empty hands, no crash.

Add / update desk

One syntax, two behaviors: d[key] = value creates the drawer if the label is new, overwrites if it exists. And remember — no dot access (d.key is a different animal entirely), no seat numbers (d[0] is a KeyError, not a position).
