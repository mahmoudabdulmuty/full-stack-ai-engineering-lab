Module 3 — keep the disk file, live handle, in-memory values, and parser as separate things.

open(path, "r") gives a handle. .read() pours the whole file into one string you can slice, test with in, print, feed to an f-string. .close() releases the handle. Step through the loop over three files below.

The four things people accidentally call “the file”

1. Path + disk file"practice/data/a.txt"
Persistent location and contents.
2. File handlefile = open(path, "r")
Live resource with mode and cursor.
3. In-memory valuetext = file.read()
A string that survives handle close.
4. Parser / collectionDictReader(file)
Lazy row parser; collect rows into a list.
Closing affects the handle. It does not delete the disk file, the string already read, or dictionaries already collected. 
files = ["madrid.txt", "tokyo.txt", "cape-town.txt"]
for fname in files:
    f = open(fname, "r")     # handle
    text = f.read()          # one string
    f.close()                # release
    if "restaurant" in text:
        print("food:", fname)

CSV lab: watch a lazy reader become a reusable list

DictReader needs an iterable of complete lines. The open handle supplies lines lazily. The collected list remains after the with block closes the handle. 

with open("players.csv", encoding="utf-8", newline="") as file:
    reader = csv.DictReader(file)   # lazy parser
    players = []
    for row in reader:             # one dict per CSV record
        players.append(row)

# handle closed; players still usable
