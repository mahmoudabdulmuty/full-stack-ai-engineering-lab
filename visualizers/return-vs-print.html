Visualizer — return vs print

Module 1. Two machines that look identical outside — and could not be more different inside.

Core model: print is a loudspeaker — sound comes out, nothing comes back (None). return is a courier — silent, but it puts a real value back in the caller's hands. Store from the loudspeaker and all you get is None.

Machine A — the courier (returns)

def add(a, b):
    return a + b

Machine B — the loudspeaker (prints)

def show(a, b):
    print(a + b)

When the wrong choice bites: three lines after result = show(2, 3), you write result * 2 — and Python throws TypeError: unsupported operand type(s) for *: 'NoneType' and 'int'. The crash is miles from the crime. Rule: need the value later → return it. Just want it seen → print it. Same rule for the course helpers: get_llm_response vs print_llm_response.
