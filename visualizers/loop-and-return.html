Visualizer — return vs the loop

Step through find_player one line at a time. Watch WHEN the function leaves the building.

The rules, in three lines: for = a turnstile, one player per pass. return = the building's exit door — whoever touches it leaves the whole function, loop included, that instant. If the turnstile runs out of players, the function falls through to the line after the loop. 

def find_player(squad, name):
    for player in squad:
        if player["name"] == name:
            return player
    return None
