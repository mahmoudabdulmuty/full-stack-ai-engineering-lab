Lesson 0005 — Customizing Prompts with Data

Module 2, Lesson 4. One win: feed structured lists and dictionaries into dynamic prompt templates for the LLM.

In M2L3 you learned how to store and access key-value pairs in dictionaries. In this lesson, we connect that structured data directly to LLM prompts — turning raw dictionaries into dynamic AI instructions.

1 · Structured Profiles to Prompts

profile = {
    "name": "Vinicius Jr",
    "position": "Winger",
    "preferred_drills": ["1v1 finishing", "pace dribbling"],
    "fitness_rating": 8,
}

prompt = f"""Generate a plan for {profile['name']}:
- Position: {profile['position']}
- Focus: {profile['preferred_drills'][0]}
- Rating: {profile['fitness_rating']}/10"""

You can interpolate dict keys (profile['name']) and chained list lookups (profile['preferred_drills'][0]) straight inside f-string curlies.

2 · The Evaluation Trap: f-strings Are Not Reactive

profile["fitness_rating"] = 8
prompt = f"Intensity: {profile['fitness_rating']}" # Evaluates to "Intensity: 8"

profile["fitness_rating"] = 9  # Dict changes...
print(prompt)                  # Still prints "Intensity: 8"!

In Python, an f-string evaluates immediately into a frozen string. If you mutate dictionary data or lists, you must rebuild or reassign the prompt string to reflect the updates.

3 · Combining Standalone Lists & Nested Data

available_gear = ["cones", "mini goals"]
prompt = f"Use only this equipment: {available_gear} for {profile['name']}."

Combining standalone lists with dictionary objects gives you fine-grained control over prompt assembly.

Check yourself

Inside f"Hello {user['name']}", why do we use single quotes around 'name'?

Matching outer and inner quotes (e.g. "..." containing "...") creates parsing ambiguity in older Python versions. Alternating single and double quotes avoids syntax errors.

Given d = {"score": 10}, p = f"{d['score']}", followed by d["score"] = 20. What is the value of p?

f-strings produce an ordinary, immutable string value upon execution. They are not live bindings or templates.

If user = {"skills": ["passing", "shooting"]}, what does f"{user['skills'][1]}" evaluate to?

Chained lookups work in f-strings: user['skills'] retrieves the list, and [1] selects the second item ("shooting").
