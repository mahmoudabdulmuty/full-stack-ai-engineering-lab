Lesson 0004 — Dictionaries

Module 2, Lesson 3. One win: replace fragile index lookups with named keys — the coach calling players by name instead of jersey number.

In M2L2 you scaled the task list with a for loop — but the pain point stayed: promotional_descriptions[1] was chocolate only because you remembered seat 1. With 40 flavors, seats are useless. A dictionary is the roster where you call the player by name.

1 · The payoff — find by name

ice_cream_flavors = {
    "mint chocolate chip": "Mint ice cream loaded with chocolate chunks",
    "cookie dough":        "Vanilla ice cream loaded with cookie dough chunks",
    "salted caramel":      "Caramel ice cream with a salted caramel ribbon",
}
cookie_dough_desc = ice_cream_flavors["cookie dough"]

Curly braces, key: value, commas. Access with square brackets and the KEY — like JS obj["key"], no dot notation. No positions, no IndexError — only keys.

2 · Missing keys — KeyError vs safe access

ice_cream_flavors["mango"]        # KeyError — crashes
ice_cream_flavors.get("mango")    # None   — safe
ice_cream_flavors.get("mango", "?")  # "?"  — custom default
"mango" in ice_cream_flavors      # False  — membership test

Python has no undefined. Missing key = KeyError. Use .get() when the key might not exist; use in for a boolean check.

3 · Add & update — same pattern

# Add
ice_cream_flavors["rocky road"] = "Chocolate ice cream with marshmallows and nuts"
# Update — identical syntax, existing key gets overwritten
ice_cream_flavors["rocky road"] = "Chocolate ice cream with marshmallows and nuts (fixed)"

One syntax covers both. No push, no splice — just assign to the key.

4 · Values can be ANY type — including lists

isabel_facts = {
    "age": 28,
    "favorite_color": "red",
}
isabel_facts["cat_names"] = ["Charlie", "Smokey", "Tabitha"]  # value is a LIST

A dict value is just a variable. It can be a string, int, float, bool, list, another dict — anything.

5 · The priority pattern — dict of lists + for loop

prioritized_tasks = {
    "high priority":   ["Compose a brief email", "Create an outline"],
    "medium priority": ["Schedule a meeting", "Draft a project update"],
    "low priority":    ["Clean up the desktop"],
}
for task in prioritized_tasks["high priority"]:
    print_llm_response(f"Please complete this task: {task}")

The dict groups lists by name. prioritized_tasks["high priority"] IS a list — loop it exactly like M2L2.

Check yourself

What does ice_cream_flavors["mango"] do when "mango" isn't a key?

Python dicts have no silent missing-key behavior — they raise KeyError. Use .get() for safe access.

How do you safely check if "mango" exists as a key without risking an error?

The in operator works on dict keys directly — returns True/False. No has_key() in Python 3.

What does ice_cream_flavors.get("mango") return if "mango" is missing?

.get(key) returns None by default when the key is absent — no exception. Pass a second argument for a custom default: .get("mango", "?").

You have a dict d = {"a": 1}. After d["a"] = 2 and d["b"] = 3, what is d?

Assignment to an existing key updates it; assignment to a new key adds it. Same syntax, same line.

isabel_facts["cat_names"] holds a list. What does isabel_facts["cat_names"][0] return?

The value is the list. Chaining ["cat_names"][0] indexes into that list — first element is "Charlie".
