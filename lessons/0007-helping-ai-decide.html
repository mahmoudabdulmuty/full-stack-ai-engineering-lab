Lesson 0007 — Helping AI Decide

Module 2, Lesson 6. One win: branch per item — act now or save for later — inside one loop.

A captain picks the starting XI: players who make the cut play, the rest go to the bench. `if` is the team sheet, `else` is the bench list.

1 · Anatomy of a decision

if task["minutes"] <= 5:
    print_llm_response(f"Do now: {task['description']}")
else:
    later_tasks.append(task["description"])

No parentheses around the condition. The : starts each block; indentation is membership (4 spaces). else: aligns with its if.

2 · Nested decisions in loops

for task in tasks:
    if task["minutes"] <= 5:
        print_llm_response(...)      # 8 spaces: inside if, inside loop
    else:
        later_tasks.append(...)

Nesting adds indent levels — 4 per block. The un-indented code after the loop runs once, when everything is decided.

3 · The full pipeline — decide + accumulate + measure

later_tasks = []
for task in tasks:
    if task["minutes"] <= 5:
        print_llm_response(f"Complete now: {task['description']}")
    else:
        later_tasks.append(task["description"])
print(len(later_tasks))

M2 in four lines: list-of-dicts data (L1/L3), loop (L2), f-string prompt (L4), conditional branch (L6). Measure with len() after — don't guess.

Check yourself

A task takes exactly 5 minutes. Which condition includes it in "do now"?

< excludes exactly-5; <= includes it. And => isn't an operator — assignment inside a condition can't even parse.

Where must else: sit relative to its if?

if/else pairs align vertically; the interpreter matches them by indentation level.

print(len(later_tasks)) sits flush-left after the loop. When does it run?

Indentation is membership: flush-left means outside the loop. It runs once, after the full pass — measuring the finished accumulator.
