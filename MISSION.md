# Mission: Python + AI development for a frontend engineer

## Why
Mahmoud is a 4-year frontend developer (Vue 3 / Quasar / Pinia, light TypeScript) who wants Python as a second language — specifically to build AI-powered tools and understand how LLM calls work under the hood, not just to tick a box. The concrete outcome is being able to ship real Python + LLM things: automating his own busywork (summaries, batch text processing, content generation) and contributing Python on the job. Deeper driver (M2 close): escape "prompt jockey" mode — after ~1.5 years of prompt-only work, rebuild the hands-on engineering muscle. AI is the stats department; Mahmoud reads the game.

## Success looks like
- Completes all 4 modules of the DeepLearning.AI "AI Python for Beginners" curriculum 1:1 with the tutor (platform videos skipped; transcripts fetched and taught directly). Certificate OPTIONAL — pursue later via subscription if wanted; the curriculum itself is already covered.
- Escapes "prompt jockey" mode: writes, predicts, and debugs code BY HAND — AI as a tool, engineering judgment as the moat.
- Can build a small end-to-end Python script that reads data, calls an LLM API, and does something useful with the response — without copying the course notebooks.
- Can explain, in his own words, what happens when `get_llm_response()` runs, and why storing vs printing a response matters.
- Ports a familiar concept from JS/TS to Python fluently (arrays → lists, objects → dictionaries, etc.).
- Passes the end-of-module interview-style tests and the final per-module technical screening.
- Ships one personal automation project using Python + an LLM API — built solo, tutor as reviewer.

## Constraints
- Frontend background: knows programming concepts, Python beginner. JS/TS analogies land well and should be used.
- Teaching style: Socratic, no spoilers on errors, football/soccer analogies (no cooking) — Barcelona/Al-Ahly players ONLY (learner is cúlé + Ahlawy; Real Madrid players are banned), mini challenges after each module, knowledge checks, honest direct feedback. Keep pace reasonable.
- Learning records and references live in `./ai-python-tutor/` under Downloads.
- All practice happens in local `.py` practice files with stubbed LLM helpers (no API key needed); code is ALWAYS learner-written, chat is for reasoning.

## Out of scope

- Math / machine-learning modeling — that's a different specialization.
- Python web frameworks (Django/FastAPI) — not part of this course.
